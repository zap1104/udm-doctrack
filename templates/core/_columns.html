{% comment %} One month's columns, each with its value above it. Shared by the three column charts so the labelling rule is written once. Every series in a month that has anything in it gets a number, a zero included: a zero draws no bar (a stub would paint a value that is not there), so without its "0" a series would simply be missing. A month with nothing in any series draws nothing, because the axis already says 0. Each column carries a title naming its series, month and value, for a reader hovering on a desktop.
