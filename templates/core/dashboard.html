How to read this

Each month is the position at the end of that month, counted from the first document in the system — not that month on its own. A month with nothing finished still shows every document finished before it.

Created and Completed count documents; the gap between them is the work still in the building. Handovers count moves between offices, so one document endorsed four times adds four — which is why that bar is usually the tallest and why it is not a count of documents. Each bar carries its own number so the three are never mistaken for one another.
