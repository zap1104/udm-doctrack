{% comment %} One inline SVG icon, chosen by name. Usage: {% include "partials/_icon.html" with name="send" %} {% include "partials/_icon.html" with name="print" class="empty-state-ic" %} Inline rather than an or an icon font on purpose: the stroke is `currentColor` (set in .btn-ic), so a single markup snippet inherits whatever colour the button, pill or panel around it happens to use. A sprite sheet would need a fill override per context, and an icon font would fail to a tofu box rather than to nothing. Every icon here is decorative — it repeats a label that is already printed beside it — so all of them carry aria-hidden and are skipped by a screen reader. If you ever use one *without* a visible label, do not reach for this partial; that icon needs a role and a name of its own. Geometry is a 24x24 box with no fills, matching the stroke-based set the rest of the UI is drawn in. Keep new icons on that grid or they will not optically match the ones already here. {% endcomment %}
