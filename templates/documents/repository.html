{% comment %} Folders across the full width rather than squeezed into a quarter-width rail. A repository is a filing room: the first thing a reader wants is the drawers, and in a narrow column the office names truncated to the point where two offices read the same. Equal columns because no office's drawer is more important than another's — the count inside each is the only ranking. The column count is settings-driven (REPOSITORY_FOLDER_COLUMNS, default 4) because the team has not settled on a number; it is one line to change. {% endcomment %}
