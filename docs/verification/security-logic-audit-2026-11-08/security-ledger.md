# Security coverage

This ledger describes the access contract and the evidence used to evaluate each feature family. The [audit report](../security-logic-audit-2026-11-08.md) records the actual run outcomes. A suite reference covers the scenarios defined by its tests. It does not certify every combination of route, role, setting and input.

| Surface | Expected access or safety property | Evidence and disposition |
| --- | --- | --- |
| Login, Django admin sign-in, OTP, verification, password reset, session expiry and recovery | Active accounts authenticate with a fresh OTP when enabled. Codes and invitations expire and cannot be replayed. Existing roles and native admin staff requirements still apply. | Account and OTP suites, actual browser sign-in, recovery command tests and `test_nov8_auth_invalidation.py`. Fixed old security credentials becoming valid again after a security setting was reverted. |
| User capabilities, record sharing, admin and office scope | A capability can only narrow authority. A share grants reading only. Viewers cannot write. Office authority, custody and draft privacy continue to apply even to crafted requests. | Existing capability policy, visibility and admin tests. New exact-ID External role cases in `test_nov8_logic_oracles.py`. Production provider, proxy and identity configuration was not exercised. |
| OVPA and External Tracking actions | Confirm receipt as the actual recipient. External corrections require responsible-office authority and retain provenance. Stale, forged and unauthorized writes must not change state. | Existing Tracking and External transition, correction and permission tests. New independent External transition trace checks refused actions and resulting persisted state. |
| Uploads, previews, original and version downloads, private storage, saved uploads and locks | Authorize content against the current record and account. Signed links do not replace current authorization. Filed contents remain immutable. Never send active preview content or load a different store's same-key file. | Existing upload, staged file, file version and preview tests. Notifications and private audit data retain their intended audiences. | Full feature suites, exact-ID filter checks, seeded reconciliation and role smoke. ## Scope of static findings

- The DOCX parser lead was confirmed. A raw ASCII search for DTD declarations missed UTF-16. Rejecting a declaration at the parser boundary works on both supported UTF-16 byte orders. Malformed encoding, unsupported ZIP compression and excessive XML nesting return an invalid-preview response.
- The QR SVG is generated by Segno from the application's input and has its title label escaped. The flagged `mark_safe` call is not a free-form HTML rendering path.
- The OCR URL findings identify server-configured provider calls. The initial URL is checked for HTTPS and the permitted provider host. These checks did not send network requests to a provider or establish behavior for every deployment proxy or provider redirect.
