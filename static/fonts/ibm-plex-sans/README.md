# IBM Plex Sans

Official IBM package: @ibm/plex-sans 1.1.0.
Source: https://github.com/IBM/plex
Files: complete WOFF2 Regular (400), Medium (500), SemiBold (600), Bold (700).
Distributed under the SIL Open Font License in LICENSE.txt.
Loaded locally throughout the application by static/css/app-theme.css.
Screen body text and form controls use a 14px base size, with larger headings
and smaller secondary metadata for hierarchy. Print layouts retain their own styles.
